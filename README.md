## 🦉 关于 Wing

**Wing** 这个名字承载着双重意象：

- **羽毛笔（Quill）**：象征着书写与记录，用轻盈的笔触捕捉生活的片段
- **翅膀（Wing）**：像黄昏时分的猫头鹰收拢翅膀，整理一天的思绪与回忆

黄昏是猫头鹰最活跃的时刻，也是我们回顾一天、整理思绪的最佳时机。Wing 就像一只智慧的猫头鹰，在黄昏时分帮你将零散的记录编织成完整的日记，让思绪如羽毛般轻盈，如翅膀般自由。

## ✨ 特性

### 核心功能
- **碎片化记录**：随时记录零散的想法和图片，无需立即处理
- **AI 智能合成**：使用 Gemini API 将碎片化记录合成为结构化的日记
- **图片支持**：支持上传图片，AI 会在日记中智能插入
- **心情分析**：AI 分析你的心情，提供心理学洞察
- **待办提取**：自动从记录中提取待办事项

### 数据管理
- **本地优先**：所有数据首先存储在本地（localStorage）
- **WebDAV 同步**：支持通过 WebDAV 备份到云端（默认支持坚果云）
- **数据导入/导出**：支持 JSON 格式的数据导入和导出
- **隐私保护**：所有 API 密钥本地存储，不会上传到服务器

### 用户体验
- **极简设计**：简约优雅的界面设计，大量留白
- **多语言支持**：支持简体中文和英文
- **响应式布局**：适配不同屏幕尺寸
- **实时反馈**：操作即时反馈，流畅的动画效果

## 🚀 快速开始

### 环境要求
- Node.js 16+ 
- npm 或 yarn

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd Wing
```

2. **安装依赖**
```bash
npm install
```

3. **配置环境变量**
创建 `.env.local` 文件：
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

4. **启动开发服务器**
```bash
npm run dev
```

应用将在 `http://localhost:3000` 运行

### 构建生产版本
```bash
npm run build
npm run preview
```

## 🌐 部署到 Netlify

Wing 支持一键部署到 Netlify，提供免费的静态网站托管服务。

### 部署方式

#### 方法 1：通过 GitHub 自动部署（推荐）

1. **登录 Netlify**
   - 访问 [Netlify](https://www.netlify.com/)
   - 使用 GitHub 账号登录

2. **导入项目**
   - 点击 "Add new site" → "Import an existing project"
   - 选择 GitHub，授权并选择 `BHnuit/Wing` 仓库

3. **配置构建设置**
   - Build command: `npm run build`
   - Publish directory: `dist`
   - 这些设置通常会自动检测，项目已包含 `netlify.toml` 配置文件

4. **配置环境变量（可选）**
   - 进入 "Site settings" → "Environment variables"
   - 添加 `GEMINI_API_KEY`（可选，用户也可以在应用内设置页面配置）

5. **部署**
   - 点击 "Deploy site"，Netlify 会自动构建并部署
   - 部署完成后会获得一个免费的 `.netlify.app` 域名

#### 方法 2：手动部署

1. **本地构建**
   ```bash
   npm run build
   ```

2. **上传到 Netlify**
   - 登录 Netlify
   - 将 `dist` 文件夹拖拽到部署区域

### 部署注意事项

- ✅ **路由支持**：项目使用 HashRouter，Netlify 无需额外配置
- ✅ **环境变量**：可在 Netlify 中配置 `GEMINI_API_KEY`，但用户也可以在应用内设置
- ⚠️ **WebDAV 功能**：开发环境的 WebDAV 代理在 Netlify 上无法使用。生产环境需要：
  - 使用支持 CORS 的 WebDAV 服务器，或
  - 使用 Netlify Functions（需要付费计划），或
  - 客户端直接访问（如果服务器支持 CORS）

### 配置文件说明

项目已包含以下 Netlify 配置文件：

- `netlify.toml` - Netlify 部署配置（构建命令、路由规则、安全头等）
- `.netlifyignore` - 忽略不需要部署的文件（如 `node_modules`、`.env` 等）

## 🔧 技术栈

- **前端框架**: React 19 + TypeScript
- **构建工具**: Vite 6
- **路由**: React Router v7
- **UI 组件**: Lucide React (图标)
- **样式**: Tailwind CSS (CDN)
- **AI 服务**: Google Gemini API
- **数据存储**: localStorage
- **同步协议**: WebDAV

## ⚙️ 配置说明

### Gemini API 配置
1. 访问 [Google AI Studio](https://makersuite.google.com/app/apikey)
2. 创建 API 密钥
3. 在设置页面填入 API 密钥

### WebDAV 配置（坚果云）
1. 登录坚果云，进入"账户安全"
2. 生成"应用密码"（非登录密码）
3. 在设置页面配置：
   - 服务器 URL: `https://dav.jianguoyun.com/dav/`
   - 用户名: 坚果云用户名或邮箱
   - 密码: 应用密码

## 📱 使用流程

1. **记录碎片**：在聊天界面输入文字或上传图片
2. **智能合成**：点击猫头鹰图标（🦉）的"智能编织今日"按钮，AI 会生成结构化日记
3. **查看日记**：在日记库中浏览所有生成的日记
4. **云端备份**：在设置中配置 WebDAV 并同步数据

## 🔒 隐私与安全

- 所有数据存储在本地浏览器中
- API 密钥仅存储在本地，不会上传
- WebDAV 同步使用 HTTPS 加密传输
- 支持完全离线使用（除 AI 合成功能外）

- **功能描述**：聊天界面已发送的消息允许重新编辑
- **使用场景**：用户发送消息后发现有错别字或想补充内容时，可以点击消息进行编辑
- **实现要点**：
  - 在消息气泡上添加编辑按钮
  - 支持内联编辑或弹出编辑框
  - 更新消息时间戳或添加编辑标记

### 2. 日记重新生成功能
- **功能描述**：已生成的当天日志支持根据完整的一天内容重新生成
- **使用场景**：例如中午12点已经生成了日记，但晚上6点又有了新的记录，此时可以重新生成包含所有记录的完整日记
- **实现要点**：
  - 在日记详情页添加"重新生成"按钮
  - 合并当天所有记录（包括已生成后的新记录）
  - 可选择覆盖原日记或创建新版本

### 3. 聊天记录查看优化
- **功能描述**：
  - 记录界面只展示当天的聊天内容
  - 日记库界面在日记内容页面的右上角增加查看当天聊天记录的选项
  - 用户可以从这个入口回到特定日期的聊天界面
- **使用场景**：查看历史某一天的完整聊天记录，回顾当天的所有碎片化记录
- **实现要点**：
  - 聊天界面按日期过滤显示
  - 日记详情页添加"查看当天记录"按钮
  - 支持日期导航和切换

### 4. AI 模型配置扩展
- **功能描述**：
  - 聊天模型的 API 增加 OpenAI 支持
  - 支持自定义 base 地址
  - 增加测试 API Key 连接选项
- **使用场景**：用户可以选择使用不同的 AI 服务（Gemini、OpenAI 等），或使用自部署的 API 服务
- **实现要点**：
  - 设置页面添加模型选择（Gemini / OpenAI / 自定义）
  - 支持配置自定义 API base URL
  - 添加"测试连接"按钮验证 API Key 有效性
  - 统一 AI 服务接口，支持多模型切换

### 5. 日记手动编辑功能
- **功能描述**：日记内容页面的右上角增加手动编辑选项，用户可以在生成的内容基础上重新编辑标题和内容
- **使用场景**：AI 生成的内容需要微调，或用户想添加个人补充说明
- **实现要点**：
  - 日记详情页添加"编辑"按钮
  - 支持编辑标题和 Markdown 内容
  - 保存编辑后的版本，保留编辑历史（可选）

### 6. 空白引导提示
- **功能描述**：当聊天界面为空白时，随机浮现几个提问，引导用户对当天的生活进行复盘思考和感悟
- **使用场景**：用户打开应用但不知道记录什么时，通过引导性问题启发思考
