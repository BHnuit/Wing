# 更新日志

## [0.2.1] - 2026-01-26

### 新增功能

- **AI 长期记忆（Beta 功能）**：从日记中自动提取用户画像，让 AI 更了解你，生成更个性化的日记反馈
- **日记库搜索功能**：支持按标题、内容、日期搜索，实时搜索，关键词高亮
- **测试框架**：集成 Vitest 单元测试和 Playwright E2E 测试，提升代码质量和稳定性
- **统一错误处理**：新增 `errorHandler` 工具，提供统一的错误分类、格式化、日志记录和用户友好的错误消息

### 功能增强

- **AI 服务**：集成记忆上下文到日记生成流程，提供更个性化、更有温度的反馈
- **设置界面**：新增记忆管理入口，支持记忆相关配置
- **数据服务**：优化数据导入导出功能，支持更多导入方式

### 优化改进

- **Safari 浏览器兼容性**：修复 Safari 浏览器传图失败问题
- **性能优化**：图片懒加载、防抖/节流优化，提升页面加载速度和交互流畅度
- **代码分割**：按路由懒加载组件，减少初始加载时间，提升首屏性能
- **记忆管理**：智能合并相似记忆，提高记忆库质量
- **存储设置界面**：简化存储管理界面，移除 WebDAV 相关功能，聚焦本地数据管理
- **开发体验**：更新 Vite 配置支持测试环境，优化开发工作流
- **项目配置**：更新 `.gitignore`，排除测试生成的临时文件和报告

## [0.2.0] - 2026-01-23

### 新增功能

- **PWA 支持**：应用可安装为桌面/移动应用，支持离线访问
- **智能图片布局**：自动识别横图、竖图、超长图，优化阅读体验
- **图片查看器**：点击图片放大查看，支持缩放、拖拽、键盘导航
- **文件夹导入**：支持从文件夹导入备份数据（兼容 WebDAV 导出格式）
- **移动端下载优化**：改进移动浏览器的数据下载体验

### 功能增强

- **Markdown 渲染器**：智能段落分割，竖图文字环绕效果
- **数据服务**：新增 `importDataFromFolder` 和 `replaceDataFromFolder` 方法
- **日期工具**：新增时间戳格式化函数，支持中英文格式
- **ChatView**：优化聊天界面交互体验
- **JournalDetail**：改进日记详情页显示效果
- **SettingsStorageView**：增强存储设置界面功能

### 优化改进

- **AI 服务**：优化 Gemini API 调用逻辑
- **WebDAV 服务**：改进同步功能和错误处理
- **国际化**：新增 PWA 相关翻译文本
- **图标资源**：更新应用图标，新增多尺寸图标文件

### 技术更新

- 更新依赖包
- 新增图标尺寸调整脚本
